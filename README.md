# Project Daily

> 하루의 일정을 시각적으로 관리하고, 현재 일정에 집중하기 위한 데스크톱 일정 관리 프로그램

<p align="center">

**Project Daily**는 Python과 CustomTkinter를 기반으로 제작한 개인 일정 관리 프로그램입니다.

일정을 등록하면 현재 시간에 맞춰 자동으로 현재 일정을 인식하고,
실시간 카운트다운과 원형 진행률을 통해 남은 시간을 직관적으로 보여줍니다.

</p>

---

## Preview

### Main Features

- 실시간 현재 시각 표시
- 일정 추가 / 삭제
- 일정 시간 중복 검사
- 일정 자동 정렬
- 현재 진행 중인 일정 자동 인식
- 1초 단위 실시간 카운트다운
- 원형 진행률 타이머
- 일정별 색상 구분
- 전체화면 집중 타이머
- JSON 기반 일정 데이터 저장
- Git / GitHub 기반 버전 관리
